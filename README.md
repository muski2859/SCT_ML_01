# House Price Prediction using Multiple Linear Regression

## Project Overview

This project implements a Multiple Linear Regression model to predict house prices based on key housing features such as living area, number of bedrooms, and number of bathrooms.

## Dataset

The dataset used is the House Prices dataset from Kaggle.

## Features Used

* GrLivArea (Ground Living Area)
* BedroomAbvGr (Number of Bedrooms)
* FullBath (Number of Bathrooms)

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib

## Steps Performed

1. Loaded and explored the dataset.
2. Selected relevant features and target variable.
3. Split the dataset into training and testing sets.
4. Trained a Multiple Linear Regression model.
5. Predicted house prices on test data.
6. Evaluated model performance using MAE, RMSE, and R² Score.
7. Visualized Actual vs Predicted house prices.

## Model Performance

* MAE: 35,788.06
* RMSE: 52,975.72
* R² Score: 0.6341

## Sample Prediction

For a house with:

* Living Area: 2000 sq ft
* Bedrooms: 3
* Bathrooms: 2

Predicted House Price: 240,377.51

## Conclusion
The model successfully predicts house prices using selected housing features and explains approximately 63.4% of the variation in house prices.
